Qt / Vulkan Window Example
==========================

A basic Vulkan window in Qt, following example [here](https://doc-snapshots.qt.io/qt5-dev/qtgui-hellovulkanwindow-example.html):



Prerequisites
-------------

Arch Linux:
```
sudo pacman -Syu cmake qt5 vulkan-icd-loader vulkan-headers vulkan-validation-layers vulkan-tools
```

Installation
------------

```
mkdir build
cd build
cmake ..
make
```
