API Reference
=============

The classes a program or a new module works with, from the comments in the
headers (generated by doxygen). The headers are under
:tree:`shift/core`; include them as ``shift/core/...``, and link
``shift_core_dep`` in meson.

Loading and running a model:

.. code:: cpp

   #include "shift/core/context.h"

   shift::core::Context context;
   context.LoadJSON("pendulum.json");
   context.set_state_observer(
     [](double t, const std::vector<double>& y) { /* each output step */ });
   context.Simulate();
