CONTROLS
The left mouse button is used to rotate the scene about the world X and Y axes.
The right mouse button is used to pan the scene.
The middle scroll wheel is used to zoom in and out.


RENDERING
Select wireframe or flat-shaded mode from the view menu.
Orthographic and perspective projection can also be chosen in the view menu.


OPENING A SCENE
All scenes and their respective obj files are located under the "scene" folder. Open the scene by selecting "Open" from the File menu and navigating to the directory. 

I chose not to change the file format for the scenes, therefore color data is not saved. However it is possible to change the color of any object for the current session if you do not like the randomly chosen color.


EDITING A SCENE
Important: a model must be selected in the TreeWidget dialog box at right to change the position and orientation of an object.
