# Synopsis

## Notable changes from v0.1 to v0.2 of star2 file format

### 0.2
* Using .json extension
* Changed frames, bodies, assemblies and joints to arrays. Quantities are now accessed by index into array, rather than using descriptive name as key
* changed "body_def" tag to "definition"
* changed "star_version" tag to "version"
* changed "assembly" tag to "assemblies" and allow multiple assemblies stored at top level

### 0.1
* Initial version of file format
